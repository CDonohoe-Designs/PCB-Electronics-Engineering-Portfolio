## Selected Projects

### Nordic BLE Hardware & Firmware Engineering
Custom nRF52840 hardware design with GNSS, LiPo power, sensor interfaces, KiCad PCB layout and manufacturing handoff, complemented by Zephyr/nRF Connect SDK embedded C, custom BLE GATT, real sensor measurements and live EnviroVue application validation on Nordic development hardware.

[**View the 9-page Nordic BLE Engineering Portfolio (PDF)**](Portfolio/Nordic_nRF52840/Nordic_BLE_Engineering_Portfolio_Working_v5.pdf) · [Project overview](Portfolio/Nordic_nRF52840/README.md)

### ESP32-S3 Wireless Hardware & Embedded Engineering
Four-layer, 41 × 41 mm ESP32-S3 PCB design in KiCad integrating MAX-M10S GNSS, motion and environmental sensors, LiPo power and expansion interfaces. The nine-page portfolio also documents embedded C++ firmware, Wi-Fi/JSON telemetry, JLCPCB manufacturing preparation and live system validation on separate ESP32-S3 development hardware.

[View the 9-page ESP32-S3 Engineering Portfolio (PDF)](Portfolio/ESP32S3/ESP32S3_Engineering_Portfolio_Complete_9Pages.pdf)

### USB 5 Gbit/s to Gigabit Ethernet Adapter
High-speed four-layer PCB design based on the Microchip LAN7800, including schematic capture, controlled-impedance USB/Ethernet routing, DRC and fabrication outputs.

[View project repository](https://github.com/CDonohoe-Designs/USB3-Gigabit-Ethernet-Adapter-Portfolio)

### STM32WL LoRa Sensor Board
Mixed-signal wireless sensor design combining STM32WL, sub-GHz / LoRa RF, analogue signal conditioning, ADC acquisition, power architecture and circuit simulation.

[View project repository](https://github.com/CDonohoe-Designs/STM32WL-LoRa-Sensor-Board-Portfolio)
