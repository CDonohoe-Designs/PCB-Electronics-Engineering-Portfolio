## Overview

This portfolio documents ESP32-S3 embedded hardware design and complementary firmware development, from system architecture and four-layer KiCad PCB layout to manufacturing preparation, sensor acquisition, Wi-Fi connectivity and live application telemetry.

The project brings together a custom **41 × 41 mm four-layer ESP32-S3 PCB** with embedded C++ development and practical sensor, Wi-Fi and application demonstrations on physical ESP32-S3 development hardware.

## Hardware and PCB engineering

- Custom four-layer ESP32-S3 wireless and sensing PCB designed in KiCad, with Wi-Fi/BLE-capable processing and expansion interfaces.
- MAX-M10S GNSS with external active-antenna connection.
- BMI323 motion sensing, ADXL372 high-g acceleration sensing, BME688 environmental sensing and VEML6035 ambient-light sensing in the custom hardware design.
- Single-cell LiPo power architecture, USB interface and external peripheral connectivity.
- Hierarchical schematic capture, functional partitioning, component placement, routing and design-for-manufacture/test review.
- Gerber/drill files, BOM, CPL/pick-and-place data, component sourcing and JLCPCB assembly quotation-stage preparation.

## Firmware, connectivity and application validation

- Embedded C++ development using PlatformIO and the Arduino framework on ESP32-S3 development hardware.
- Physical sensor acquisition, including BME680 environmental and BH1750 ambient-light measurements on the development setup.
- Serial debugging, structured JSON measurements, Wi-Fi connectivity and connected telemetry.
- EnviroVue live client showing environmental measurements and recent trends.
