# General PCB & Embedded Electronics Engineering Portfolio

[**View the complete eight-page engineering portfolio (PDF)**](PCB_IoT_Solutions_Embedded_Engineering_Portfolio.pdf)

A capability overview across five projects, with STM32WL as the lead hardware case study and Altium Designer as the primary hardware-design tool.

## Projects and evidence

| Project | Skills demonstrated |
|---|---|
| STM32WL LoRa sensor node | Altium schematics and PCB, analogue front end, 14-bit ADC, power domains, RF matching/filtering, LTspice and Python analysis |
| USB3 to Gigabit Ethernet | Altium stack-up, impedance profiles, differential-pair routing, matched-length constraints and DRC |
| Nordic nRF52840 | Custom PCB, Zephyr/nRF Connect SDK, embedded C, custom BLE GATT and live application integration |
| ESP32-S3 | Four-layer PCB, embedded C++, Wi-Fi/HTTP/JSON telemetry and physical sensor integration |
| EdgeLink S3 Cellular | Cellular/GNSS hardware, charging and power-path design, modem interfaces and manufacturing documentation |

The portfolio includes the STM32WL functional-partitioning visual, Altium constraint screenshots, circuit and signal-analysis plots, DRC evidence, manufacturing preparation and a skills-to-evidence map.

Altium Designer is used for STM32WL and USB/Ethernet. KiCad is used for the Nordic, ESP32-S3 and cellular designs. Nordic and ESP32-S3 firmware demonstrations use separate development hardware; simulation, manufacturing preparation and completed physical tests are identified separately.
